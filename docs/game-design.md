# go run ./gopher - ゲームデザイン仕様

## 概要

Go言語のマスコットキャラクター「Gopher君」がシャトルランをする2Dゲームです。

## ゲームコンセプト

タイトルは `go run ./gopher` です。Gopher がシャトルランで走る体験を、Go言語の世界観で表現します。ボタンは `go`、壁にぶつかれば `panic`、立ち直れば `recover`。成績は `go test -v` のように流れ、最後に Go Proverb が表示されます。

| ゲーム要素 | Go言語の対応 |
|---|---|
| メインボタン | `go`（全状態共通） |
| 壁衝突エフェクト | `panic`（赤点滅） |
| 復帰エフェクト | `recover`（緑フェード） |
| ゴールマーカー | `goto L` / `goto R` |
| HUD | `go test -v` 風出力（`=== RUN`, `--- PASS/FAIL`） |
| リザルト画面 | `BenchmarkGopher` 風サマリー + Go Proverb |

## 操作仕様

- **タッチ優先**（モバイルファースト）、タッチがない場合のみマウス入力
- ボタン押下時に色が変化し、離すと元に戻ります

## ゲーム状態

ゲームは4つの状態で管理されます。状態遷移の実装は `internal/game/game.go` を参照してください。

### Title 状態

- ゲーム起動時の初期状態
- Gopher は初期位置で静止し、ステージ・ミスカウント・ラップ数を初期化します
- `go` タップ → Pregame に遷移
- Credits ボタン → クレジット画面を表示

### Pregame 状態

- 画面中央に「GO」を表示します（300ms）
- 表示時にコールバックを実行し、Running 状態に自動遷移します

### Running 状態

- `go` タップで Gopher が加速します（複数回タップ可）
- **ステージシステム**: 7ラップごとにステージが上昇し、最大速度が上がります
- **音階タイマー**: 制限時間を8等分し、ドレミファソラシドで残り時間を通知します
- **ゴール判定**: 8音すべて鳴り終わり、かつ制限時間（maxLapTime）を超えた時点で、最後に到達したゴール側と期待方向を比較します
  - 一致 → 成功（ラップ+1）、不一致 → ミス+1
  - ゴール側の境界マージンライン通過で到達を記録します
- **失敗条件**: 2回連続ミスでゲーム終了です
- **画面端到達**: 速度がある状態で端に到達するとバウンドペナルティが発生します

### Result 状態

- ターミナル風オーバーレイ（半透明暗転）に `--- PASS/FAIL` ログ、`BenchmarkGopher` サマリー、Go Proverb を表示します
- 3秒クールダウン後に `return` ボタンが出現し、タップで Title に戻ります

### バウンドペナルティ（Gopher 内部状態）

Running 状態中に Gopher が速度を持ったまま画面端に到達した場合のペナルティです。ゲーム状態は Running のまま、Gopher の内部状態が遷移します。実装詳細は `internal/game/gopher/bouncing.go` を参照してください。

- **bound 状態**: 衝突速度に応じて跳ね返ります。進行方向が逆転します
- **stun 状態**: 着地後、衝突の強さに応じた怯み時間があります
- 復帰後、逆方向に走り出します。バウンド中も制限タイマーは継続します

## 音階システム

- **音階**: ドレミファソラシド（C4-C5、8音階）
- **音源**: プログラマティックに生成されたサイン波（ピアノ風倍音 + ADSR エンベロープ）
- **再生パターン**: 時間ベースで自動的に連続再生
  - 右方向ゴール時: 昇順（C4→C5）
  - 左方向ゴール時: 降順（C5→C4）
- **音の間隔**: 制限時間（maxLapTime）を8等分
- **特徴**: キャラクターの位置やゴール判定とは独立しています。ラップが進むと自動的に間隔が短くなります

## ゲームバランス

具体的な数値は `internal/game/constants.go` および `internal/game/gopher/helper.go` を参照してください。

主なパラメータ:
- Kick 加速値、最大速度（ステージごとに上昇）
- 制限時間（ラップごとに短縮、下限あり）
- ステージ進行に必要なラップ数
- 連続ミス上限
